\section{How to Use This Book}

These entries are for the Monster phase in \game{} (see the core rules: Combat).
Each creature has a dice pool, Hits, Deploy tag, Threat die for Initiative (unless Ambush auto-wins; see Combat: Opening), and an ordered action list resolved \textbf{top to bottom}.

Monsters do \textbf{not} spend party Energy: Medium needs a die showing at least 4; Hard Hard needs two dice showing 6.

\textbf{Targeting.} When an action says ``one character'', it hits the standing character in reach with the fewest current Hits; ``nearest'' means the smallest zone distance. Break ties toward a character without Guard, then as you choose. Down characters cannot be targeted while an ally stands.

When an adventure lists a monster by number (\#01--\#100), find that entry here. Threat Point costs for building fights are in the core rules (Campaign: Threat Budget): Minions \#01--40 cost 1, Brutes \#41--75 cost 3, Elites \#76--95 cost 6, Horrors \#96--100 cost 12.
