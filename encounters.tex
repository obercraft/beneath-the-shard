\section{How to Use This Book}

When \game{} calls for a non-combat beat---a Journey Clock tick, Gate crossing, or camp---roll \D{}{100} and open the matching entry below.
Each entry gives atmosphere first, then concrete stakes that touch Stress, Debt, Omens, and dice.

The five journey mechanics are summarized in the core rules (Non-Combat Encounters). This volume is the full table with descriptions.

\textbf{Checks.} Every check in these entries is an Attribute Check from the core rules: one character rolls their Attribute Dice (1--4, from the fitting attribute) and counts dice showing 4+ as successes. Easy needs 1 success (always roll at least 2 dice), Medium 2, Hard (or ``Hard Hard'') 3. Each companion may add 1 die for 1 Energy before the roll. Where an entry only describes the task, use the ``Which attribute?'' table in Character Creation. ``Energy'' is the party's shared track of 8; ``clock'' is the Journey Clock, which on the hex map is the party's \textbf{Supply} track (``clock $+1$'' = spend 1 Supply, ``clock $-1$'' = regain 1); Debt and Favor are marked per faction.
